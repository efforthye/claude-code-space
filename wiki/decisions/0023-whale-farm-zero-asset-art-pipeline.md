# 0023 — WHALE FARM: 외부 에셋 0 아트 파이프라인

> **⚠️ 2026-08-19 전제 정정.** 오너의 원래 말은 **"필요한 에셋은 내가 알아서 구해서 쓰라"는
> 자원 제공**이었는데, 제가 이를 **"에셋을 쓰지 말라는 제약"으로 오독**했습니다.
> 아트는 사용 가능합니다. 따라서 아래의 "외부 에셋 0"은 **강제된 결론이 아니라 선택**이며,
> 그 선택의 근거는 두 가지만 남습니다: ① 아트 물량이 1인 개발의 병목이 되지 않게 하는 것,
> ② 유료 차트 승자 다수가 UI 중심 게임이라는 관찰. **장르를 아트 물량 때문에 배제하는 논리는
> 철회합니다.** 특히 한국·일본 유료 차트 상위권의 `Servant of the Lake`, `Sally Face`,
> `The Past Within`, `서울 2033`처럼 **정적 일러스트 기반 내러티브 게임은 AI/구매 에셋과 궁합이
> 좋고 유료 차트에서 실제로 팔립니다** — 향후 아트 확장의 1순위 경로입니다.
>
> **현재 유효한 결론:** MVP는 UI 중심으로 만들되(속도), 아트는 "불가능"이 아니라
> **"다음 단계에서 얹는 것"**으로 취급합니다. 라이선스 위생 규칙(§결정 6·7)은 그대로 유효합니다.

## 맥락

오너의 지시(2026-08-19): **에셋은 AI 생성 이미지 / 유료·무료 에셋 팩 / 조달한 것을 쓰고,
디자인은 전량 Claude가 담당한다.** 전담 아티스트는 없습니다.

이 조건은 장르 선택에 영향을 줍니다. 캐릭터 애니메이션·배경 아트·스프라이트시트를 요구하는 게임은
아트가 병목이 되어 1인+AI로는 품질을 낼 수 없습니다. 반대로 [[paid-appstore-number-one-2026]]
§4가 보여주듯 **유료 차트의 검증된 승자 다수가 "UI가 곧 게임"인 부류**입니다
(Balatro, CloverPit, Plague Inc., Reigns).

## 검토한 안

| 안 | 문제 |
|---|---|
| AI 이미지로 캐릭터·배경을 다 만든다 | 톤 일관성이 무너집니다(같은 캐릭터가 컷마다 달라짐). 애니메이션 불가. 상업권 확인 부담이 에셋 수에 비례 |
| 유료 에셋 팩 조립 | "에셋 스토어 게임" 특유의 무개성. 유료 $4.99를 정당화하는 시각적 정체성이 생기지 않음 |
| 픽셀 아트로 통일 | 물량이 여전히 큼(스프라이트·애니메이션). 1인 병목 그대로 |
| **아트가 필요 없는 미학을 채택한다** | 제약이 스타일이 됩니다 → **채택** |

## 결정

**"Corporate Dread" — 사내 BI 대시보드 미학.** 화면의 90%가 UI입니다: 표, 라인차트, 게이지,
슬라이더, 이메일 인박스, 결산 리포트. 서사는 전부 **메모와 숫자**로 전달합니다.

구체적 규칙:

1. **비트맵 에셋 0을 목표**로 합니다. 차트·게이지·아이콘·공유 카드는 전부 CSS/Canvas/SVG로 생성합니다.
2. **인물 이미지는 절차적 생성**으로 대체합니다(이름 해시 → 하프톤 실루엣 + 이니셜).
   → AI 이미지도, 스톡도 필요 없어졌습니다. 현재 계획으로 **AI 생성 이미지 없이 출시 가능**합니다.
3. **색은 주제를 말합니다.** 차가운 관공서 슬레이트 그라운드(`#0e1216`/`#161c22`)에
   따뜻한 색은 **돈 하나뿐**(골드 `#f0b34a`). 신뢰는 시안 `#5fc8d9`, 백래시는 적색 `#e0524b`.
   "이 건물에서 유일하게 따뜻한 것은 돈"이라는 명제를 팔레트가 수행합니다.
4. **타이포가 아트 디렉션**입니다. Archivo(디스플레이) + IBM Plex Sans(본문) + IBM Plex Mono(수치).
   전부 SIL OFL 1.1로 앱 번들 가능. IBM Plex는 기업용 소프트웨어의 모국어라 톤이 폰트에서 나옵니다.
5. **사운드는 CC0**(Kenney Interface Sounds / UI Audio, 100+50종). 프로토타입 단계는 WebAudio 합성.
6. **에셋 매니페스트 강제.** 모든 외부 에셋은 `apps/whale-farm/assets/LICENSES.md`에
   출처·라이선스·확인일과 함께 등록합니다. 등록되지 않은 에셋은 빌드에 넣지 않습니다.
7. **실존 게임·회사·인물을 식별 가능하게 만드는 에셋·문구·로고는 전면 금지.** 협상 대상이 아닙니다.
   모든 브랜드는 가상(Nexal Interactive, `SKY LEGENDS: Awaken`)입니다.

## 결과

- **얻는 것:** 아트가 일정에서 사라집니다. 남은 병목은 밸런스와 재미이고, 그건 몬테카를로로
  공격할 수 있습니다([[0022-whale-farm-godot-steam-first]]).
- **얻는 것:** 라이선스 리스크가 거의 0으로 수렴합니다. 현재 프로토타입의 외부 의존은
  Google Fonts CSS 한 줄뿐이며 이미지·오디오 파일이 하나도 없습니다.
- **얻는 것:** 스크린샷 가독성 — UI 자체가 게임이므로 스크린샷 한 장이 게임 설명 전체가 됩니다.
  이는 유료 차트에서 전환율을 결정하는 요소입니다(유료앱은 체험판을 줄 수 없음, [[0021-whale-farm-premium-no-iap]]).
- **비용:** 시각적 화려함으로 눈길을 사는 경로를 포기합니다. 이 게임은 **정보 디자인의 밀도**로
  승부해야 하며, 대시보드가 지루하면 게임도 지루합니다. 디자인 실패의 여지가 좁습니다.
- **비용:** 가차 카드 아트가 필요해지는 순간 이 결정을 다시 열어야 합니다. 그때는 상업권이 명시된
  플랜에서 AI 생성하고 매니페스트에 프롬프트까지 기록합니다.
