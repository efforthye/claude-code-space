# AI 영상 시장 지형 (2026) — 경쟁 특징과 mayo의 포지셔닝

Research snapshot (Feb–Apr 2026 reviews/comparisons; see sources).

## 모델/플랫폼별 특징

| 플랫폼 | 강점 | 한계 |
|---|---|---|
| Seedance 2.0 | 멀티모달 입력 12개(이미지9+영상3+오디오3), 멀티샷 필름, 최장 15s, 무료 티어 | 플랫폼 아닌 모델 — 스토리 관리 없음 |
| Kling 3.0 | 네이티브 4K@60fps, 가성비 최고, 캐릭터 중심, 무료 66크레딧/일 | 스토리텔링 도구 부재 |
| Sora 2 | 물리 시뮬·카메라, 25s 단일 클립, 스토리보드 편집 | **2026-03 서비스 종료** |
| Veo 3.1 | 씬 일관성·프롬프트 이해 1위, 네이티브 오디오, 공식 API | 비쌈, 구글 생태계 |
| Higgsfield | 카메라 컨트롤 프리셋(dolly/drone/orbit), Soul ID 캐릭터 일관성, 멀티모델 허브, Marketing Studio | 구독 진입장벽 |
| Runway/Pika | Pika = 속도(30–60s 생성)·반복작업, Runway = 프로 편집 워크플로 | 장편 구조 없음 |

## 2026 트렌드 (리뷰어들이 꼽는 것)

1. **멀티샷/멀티씬 스토리텔링**이 최대 격전지 — 단일 클립 품질은 상향평준화,
   "여러 샷을 하나의 이야기로"가 차별화 포인트 (Kling Omni, Seedance 멀티샷).
2. **캐릭터 일관성** 제품화 (Soul ID 등) — 리뷰마다 첫 평가 항목.
3. **네이티브 오디오** (Veo) 부상 — 무음 영상은 반쪽 취급.
4. **용도 특화 앱** (광고/UGC/클리핑) — 범용 생성기에서 워크플로 제품으로 이동.
5. 모델은 교체되는 부품 — **허브형(멀티모델) 플랫폼**이 승자 (Higgsfield 전략).

## mayo의 현재 강점 (이미 시장 상위 트렌드와 정렬)

- **감독(Claude) → 흐름 검수 → 이미지 검수 → 클립 게이트**: 어떤 경쟁사에도 없는
  단계별 승인 파이프라인 — 돈 쓰기 전에 이야기를 확정.
- **프레임 체이닝 + MCSLA 상세 프롬프트 + 디졸브**: 멀티씬 연속성 자동화.
- 모바일 앱 + 웹 + 커뮤니티 피드(탐색/랭킹/템플릿 리믹스) 일체형.
- 모델 추상화(seam) — Seedance/Kling로 갈아타기 쉬움 (허브형 잠재력).

## 끌어올릴 것 (추천 우선순위)

1. **비디오모델 다변화**: Higgsfield 경유로 Seedance 2.0/Kling 3.0 선택 노출
   (videoModel 카탈로그 확장) — "한 앱에서 최고 모델들" 허브 포지션.
2. **네이티브 오디오/BGM 파이프라인**: Seed Audio/ElevenLabs로 씬별 앰비언스
   + 감독이 오디오 큐도 쓰게 (무음 영상 탈출).
3. **캐릭터 시트 → Soul ID 학습 연동**: 반복 캐릭터를 사진/스틸로 고정.
4. **레퍼런스 입력**: 이미지/영상 참조 업로드 → Seedance 멀티모달 입력 활용
   ("이 느낌으로") — 리뷰어들이 가장 칭찬하는 기능.
5. **용도 프리셋**: 쇼츠/제품광고/브이로그 템플릿 (첫 화면 "어떤 영상?"과 연결).
