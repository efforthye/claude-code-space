## 1. 컨셉

### 1.1 전제

당신은 가상의 모바일 게임 회사 **Nexal Interactive**에 갓 입사한 **수익화 프로듀서(Monetization Producer)**입니다.
회사의 신작 F2P 게임이 방금 출시됐습니다. 유저는 있습니다. 문제는 매출입니다.
경영진은 12주(1분기) 안에 목표 매출을 요구합니다. 도구는 전부 당신 손에 있습니다 —
가차 확률, 에너지 타이머, 배틀패스, 한정 스킨, 푸시 알림, 인플루언서, 가격표.

그리고 유저에게도 도구가 있습니다 — 이탈, 별 1개, 그리고 스크린샷.

| 항목 | 값 |

| 장르 | 경제 로그라이트 / 라이브옵스 시뮬레이터 |

| 1차 플랫폼 | iOS (App Store 유료) · 선행 배포는 Steam(§7) |

### 1.3 왜 유료 차트에서 이길 수 있는가

[[paid-appstore-number-one-2026]] §7의 승자 패턴 7개에 대한 대조표입니다.

여기에 이 기획만의 추가 무기 두 개:

- **무료 언론.** 이 게임은 게임 업계가 자기 자신에 대해 이야기하게 만듭니다. 과금 설계는
  게임 기자·개발자·유저가 모두 화낼 준비가 되어 있는 주제이고, 화는 공유됩니다.
  광고비 0으로 도달을 사는 유일한 방법은 **담론에 올라타는 것**입니다.
- **업계 내부자 신뢰.** 실제 F2P 경제학(pity 시스템, WTP 분포, 코호트 LTV, 백래시 탄력성)을
  정직하게 모델링하면, 실제 수익화 담당자들이 "이거 진짜 우리 일이다"라며 퍼뜨립니다.
  이건 마케팅이 아니라 제품 사양으로 사는 도달입니다.

### 1.4 톤 — 여기서 실패하면 전부 실패합니다

**풍자이지 설교가 아닙니다.** 플레이어를 꾸짖으면 게임은 재미없어지고 공유되지 않습니다.
목표는 **"어, 나 지금 계산기를 두드리면서 즐기고 있는데"** 하는 자각의 순간입니다.
플레이어는 자기가 계산을 잘해서 뿌듯하고, 그 뿌듯함이 불편해야 합니다. 그 불편함이 공유됩니다.

**법적 안전선:** 실제 게임·회사·인물의 이름·로고·자산은 **어떤 형태로도 사용하지 않습니다.**
모든 브랜드는 가상(Nexal Interactive, `SKY LEGENDS: Awaken` 등)입니다. 이는 협상 대상이 아닙니다.

## 2. 코어 루프

```
[한 런 = 12주]

  주 시작
    │
    ├─ ① 대시보드 확인 ── 코호트 4종의 상태(잔액·인내심·신뢰), 지난주 매출, 평점, 백래시 게이지
    │
    ├─ ② 라이브옵스 카드 3장 중 1장 선택 ── 이번 주에 무엇을 할 것인가
    │       (가차 픽업 / 한정 스킨 / 배틀패스 / 로그인 보상 / 밸런스 패치 / 인플루언서 / 서버 점검 …)
    │
    ├─ ③ 다이얼 조정 ── 가차 확률, 가격, 광고 빈도, 에너지 회복 속도 (선택, 무료 아님 — TRUST 비용)
    │
    ├─ ④ 주말 결산 (시뮬레이션 실행)
    │       코호트별 지불 판정 → 매출 / 이탈 / 신규유입 / 평점 변화 / SNS 여론
    │
    └─ ⑤ 사내 이메일 도착 ── 임원의 압박, 동료의 우려, 유저의 편지, 커뮤니티 캡처
          (이 게임의 서사는 전부 이메일과 스크린샷으로 전달됩니다 = 아트 비용 0)

  12주 후: 목표 매출 달성 → 승진(다음 런: 더 큰 목표 + 신규 해금)
           미달 → 해고 (런 종료, 메타 진행은 일부 유지)
           백래시 임계 돌파 → 조기 파국 (스토어 순위 붕괴 → 매출 절벽 → 즉시 해고)
```

**결정의 축은 하나입니다: 지금 짜낼 것인가, 나중을 위해 남길 것인가.**
모든 카드와 다이얼은 `단기 매출 ↑ / 신뢰 ↓` 또는 그 반대의 교환비로 표현됩니다.
좋은 플레이는 **탐욕을 정확히 계산하는 것**이고, 이것이 로그라이트의 반복 동기가 됩니다.

## 3. 인앱경제 시스템 설계 (코어)

이 절이 게임의 실체입니다. 아트가 아니라 **여기가 제품의 품질**입니다.

### 3.1 유저 코호트 (4종)

각 코호트는 독립적인 지갑·심리 상태를 가진 시뮬레이션 개체군입니다.

| 코호트 | 인구 비중 | 지불의사(WTP) | 인내심 | 특성 |
|---|---|---|---|---|
| 🐋 **고래 (Whale)** | 0.2% | 매우 높음 (상한 없음에 가까움) | 낮음 | 매출의 50%+. 한 명 이탈이 재앙. 경쟁·우위·수집 욕구에 반응 |
| 🐬 **돌고래 (Dolphin)** | 3% | 중간 ($5~50/월) | 중간 | 가성비 판단. "가치"를 느끼면 반복 결제 |
| 🐟 **피시 (Fish)** | 20% | 낮음 ($0~5) | 높음 | 첫 결제 전환이 관문. 소액 미끼에 반응 |
| 👻 **무과금 (F2P)** | 77% | 0 | 매우 높음 | **직접 매출 0이지만, 여론과 신규유입의 원천.** 여론이 곧 유통 |

**핵심 긴장:** 매출은 고래에서 나오고, 성장은 무과금에서 나옵니다.
고래를 짜내는 수단(파워 판매, 확률 조작)은 무과금의 여론을 파괴합니다.
무과금을 달래는 수단(무료 배포)은 고래의 우월감(=지불 동기)을 파괴합니다.
**이 4개 개체군은 서로를 잡아먹습니다.** 게임의 재미는 전부 여기서 나옵니다.

### 3.2 재화 · 발행 구조

| 재화 | 역할 | 설계 포인트 |
|---|---|---|
| 💎 **젬 (하드 커런시)** | 유저가 현금으로 사는 발행 재화 | **묶음 단가 왜곡**(작은 팩은 비싸게, 큰 팩은 싸게)을 플레이어가 직접 설계 |
| 🪙 **코인 (소프트 커런시)** | 플레이로 획득 | 과다 발행 → 인플레이션 → 젬 가치 하락 → 매출 하락. **인플레이션이 실제 페널티로 작동** |
| ⚡ **에너지** | 플레이 횟수 제한 | 회복 속도가 곧 "결제 압력" 다이얼. 조이면 매출↑ 이탈↑ |
| 🎟 **가차 티켓** | 확률 뽑기 | pity(천장) 설계가 신뢰의 핵심 |
| ❤️ **TRUST (신뢰)** | **숨은 진짜 화폐** | 유저의 인내심 총량. 모든 착취는 TRUST를 지불해 매출을 삽니다. TRUST가 0이면 게임이 끝납니다 |

> **설계 명제:** 이 게임에서 **진짜 통화는 돈이 아니라 신뢰**입니다.
> 플레이어는 12주 동안 신뢰를 매출로 환전하는 환율을 관리합니다.

### 3.3 가차 수학 (플레이어가 직접 만지는 수치)

- **기본 확률 / pity 천장 / 소프트 pity 곡선 / 픽업 배너 비중 / 중복 보상률**
- 확률을 낮추면 기대 매출은 오르지만 **"확률 조작 의심"** 이벤트 발생 확률이 상승합니다.
- 확률을 공개(투명성)하면 TRUST가 오르고 단기 매출이 내려갑니다. **투명성이 실제 게임 자원.**
- 심리 모델: 고래는 pity까지 도달하는 것을 목표로 하고, 피시는 첫 10연차에서 판단합니다.

### 3.4 백래시 모델 (게임을 끝내는 시스템)

```
BACKLASH(t) = Σ [ 착취 강도 × 코호트 가시성 × 여론 민감도 ] − 완화 조치 − 시간 감쇠
```

- 백래시가 임계를 넘으면 **스토어 평점 하락 → 신규유입 급감 → 매출 절벽**의 3단 연쇄가 발생합니다.
- 이는 플레이어에게 "장기적으로도 착취는 손해"를 **설교가 아니라 숫자로** 가르칩니다(§1.4 톤 유지).
- 완화 카드: 사과문, 무료 배포, 확률 공개, 개발자 노트. **모두 매출을 태워서 신뢰를 삽니다.**

### 3.5 메타 진행 (로그라이트 축)

| 해금 | 내용 |
|---|---|
| 신규 라이브옵스 카드 | 12주를 버틸 때마다 카드 풀 확장 (덱빌딩의 즐거움) |
| 신규 타이틀(런 유형) | 방치형 → 수집형 RPG → 배틀로얄 → 소셜 카지노: **장르별로 경제 규칙이 다름** |
| 신규 시장 | 국가별 지불 문화 계수(고래 비중·가격 저항·규제) |
| 규제 이벤트 | 확률 공개 의무화·루트박스 금지 법안 → 후반 런의 판을 뒤집는 변수 |
| 승진 트랙 | 프로듀서 → 디렉터 → CPO. 목표가 커지고 도구가 늘어남 |

### 3.6 데일리 시드 챌린지 (유통 장치)

결과 카드가 **공유용으로 디자인된 스크린샷**으로 출력됩니다 — 매출·신뢰·별점·최종 판정 등급.

동시에 무료 바이럴 루프입니다.

## 4. 아트 디렉션 — "에셋이 필요 없는 미학"

오너 제약(AI/구매 에셋 + Claude 전담 디자인)을 **약점이 아니라 스타일로 전환**합니다.

### 4.1 비주얼 컨셉: *Corporate Dread* (기업 공포)

> 사내 BI 대시보드 · 다크 터미널 · 90년대 인트라넷 · 임원 보고 슬라이드 · 형광 그래프.

- **화면의 90%가 UI**입니다. 표, 라인차트, 게이지, 슬라이더, 이메일 인박스, 사내 메신저, 결산 리포트.
- 색: 무채 그레이 + 데이터 색 3종(매출 시안 / 신뢰 앰버 / 백래시 레드). 다크 기본, 라이트 지원.
- 타이포 주도 디자인 — 폰트가 곧 아트 디렉션. 오픈 라이선스(SIL OFL) 산세리프 + 모노스페이스 조합.
- 애니메이션은 **숫자가 올라가는 것**과 **그래프가 그려지는 것**뿐. 캐릭터 애니메이션 0.

### 4.2 에셋 물량표 (실제로 필요한 것 전부)

| 종류 | 수량 | 조달 |
|---|---|---|
| UI 아이콘 (재화·카드·상태) | 약 80종 | **Claude가 SVG로 직접 제작** — 디자인 시스템으로 일관성 확보 |
| 사내 인물 증명사진 (임원·동료·인플루언서) | 약 20종 | **AI 생성 초상** + 흑백/하프톤 후처리로 톤 통일 |

### 4.3 라이선스 위생 (타협 없음)

- AI 생성 이미지는 **상업 이용이 허용된 서비스·플랜**에서만 생성하고, 생성 도구·일자·프롬프트를
  `apps/whale-farm/assets/LICENSES.md`에 기록합니다.
- 구매 에셋은 라이선스 원문과 구매 증빙을 같은 파일에 기록합니다.
- **실존 게임·회사·인물을 식별 가능하게 만드는 어떤 에셋도 금지**합니다(로고·캐릭터·UI 카피 포함).
- App Store 심사 대응: 가차는 **게임 내 시뮬레이션**이며 실제 도박·현금 환전 요소가 없음을
  심사 노트에 명시합니다. 연령 등급은 보수적으로 설정합니다.

## 7. 유료 1위 달성 계획 — 수요 저장 (이 기획서에서 가장 중요한 절)

[[paid-appstore-number-one-2026]] §9의 부등식이 목표를 정의합니다.

```
발매일 iOS 미국 판매량 = 저장된 수요(S) × 전환율(C ≈ 0.10~0.15) × 미국·iOS 비중(G ≈ 0.4) ≥ 5,000
  ⟹  S ≥ 약 100,000명
```

**따라서 이 프로젝트의 1차 산출물은 게임이 아니라 "10만 명의 대기자"입니다.**

### 7.1 트로피 사다리 (3단) — 1위를 한 번에 사지 않습니다

| 단계 | 목표 | 필요 볼륨 `[추정]` | 시점 | 용도 |
|---|---|---|---|---|
| **1단** | 미국 유료 **Strategy/Card 카테고리 1위** | 수백~1,000장/일 | 발매 당일 | 가장 값싼 배지. 즉시 "App Store 1위" 문구 확보 |
| **2단** | **한국 유료 게임 종합 1위** | 미국의 수분의 1 `[미검증]` | 발매 1주 내 | 국내 언론·커뮤니티 도달, 배지 확보 |
| **3단** | **미국 유료 게임 종합 1위** | 약 5,000장/일 | 발매 당일 스파이크 | 최종 목표 |

3단이 실패해도 1·2단은 확보되며, 1·2단의 배지가 3단 재도전(대형 업데이트 재발매)의 탄약이 됩니다.

### 7.2 수요 저장 채널 — 이 게임에 특화된 것들

| 채널 | 왜 이 게임에 통하는가 | 목표 |
|---|---|---|
| **Steam 페이지 + 무료 데모** | 위시리스트가 유일하게 "저장 가능한" 수요 창고 (§7 부등식의 S) | 위시리스트 **10만** |
| **게임 업계 종사자 커뮤니티** | 수익화 담당자·게임 디자이너가 자기 직업을 다룬 게임을 공유합니다. 무료 도달의 최대 원천 | – |
| **게임 미디어** | "과금 설계를 플레이하는 게임"은 기자가 먼저 찾는 기사거리. **광고비 0의 대체재** | 주요 매체 5곳 |
| **HN / 레딧** (r/gamedesign, r/gamedev, r/gachagaming) | 확률·pity·LTV 수학을 진짜로 모델링했다는 사실이 논쟁을 만듭니다 | – |
| **틱톡/쇼츠/릴스** | 30초 클립: "고래 3명을 파산시켰다" / "확률을 0.1%로 내렸더니" — 숫자가 후킹 | 클립 100편 |
| **데일리 챌린지 공유 카드** | 발매 후 자가 증식 루프 (§3.6) | – |

> **경고** `[추정]`: 틱톡 게이밍 계정 오가닉 도달률은 2024년 15~20% → 2026년 초 4~8%로 하락했습니다.
> "올리면 퍼진다"는 전략은 더 이상 유효하지 않습니다. 소액 페이드 부스트 + 마이크로 크리에이터
> 협업을 전제로 계획합니다.

### 7.3 발매 이벤트 (D-Day 설계)

- **하루에 전부 발사합니다.** 유료 차트는 벨로시티 + 시간 감쇠로 계산되므로 분산 발매는 자살입니다.
- 동시 발사: iOS 발매 + Steam 정식 발매 + 미디어 엠바고 해제 + 크리에이터 영상 동시 공개 +
  데모 플레이어 전원 알림 + 데일리 챌린지 시즌 1 개막.
- 발매 요일: **화요일** (주간 미디어 사이클 상단 + 주말 소비 전 축적) — 검증 필요.
- 발매 국가: 전 세계 동시. 단 성과 측정과 배지 확보는 US → KR 순으로 추적.

### 7.4 검증 게이트 (계획을 스스로 죽이는 조건)

| 게이트 | 기준 | 미달 시 |
|---|---|---|
| G1 데모 반응 | 데모 공개 4주 내 위시리스트 **1만** | 컨셉 재설계 또는 소재 교체 |
| G2 저장 수요 | 발매 6주 전 위시리스트 **5만** | 발매 연기 + 채널 재설계 |
| G3 1위 시도 판단 | 발매 1주 전 위시리스트 **10만** | 목표를 1·2단(카테고리/한국)으로 하향, 3단은 대형 업데이트 시점으로 연기 |
| G4 재미 | 헤드리스 시뮬 + 플레이테스트에서 재플레이율 확보 | 발매 연기 (재미 없는 1위는 환불과 별 1개로 즉사) |

**G3가 이 기획서의 정직한 부분입니다.** 미국 유료 1위는 최근 사례 전원이 PC/콘솔 후광 또는 IP
보유자였습니다([[paid-appstore-number-one-2026]] §4.3). 후광 없이 1위를 하는 것은 **선례 없는 시도**이며,
그래서 Steam 선행을 통해 **후광을 우리가 만들어서** 조건을 충족시키는 것이 이 계획의 골자입니다.
