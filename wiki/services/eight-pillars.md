# 팔자 / EIGHT PILLARS — 기획서

> **6초 영상으로 팔리는 장면:** 여덟 장의 간지 카드를 네 기둥에 놓는다. 木 → 火 → 土 → 金,
> 상생 고리가 왼쪽에서 오른쪽으로 초록빛으로 불붙으며 이어지고, 점수 위로 **×3.5 → ×12 → ×47**이
> 튀어오른다. 마지막 기둥에서 金이 木을 만나 상극이 터지고 고리가 끊긴다. 화면이 붉게 식는다.
>
> **한 줄:** 오행 상생상극으로 여덟 칸의 운명을 조립해, 점수를 폭발시키는 로그라이트 덱빌더.

이 기획서는 **오너의 발언을 근거로 사용하지 않습니다.** 근거는 [[paid-appstore-number-one-2026]]의
시장 실측과 게임 디자인 논증뿐입니다. 선행 기획 [[whale-farm]]의 폐기 사유는
[[0026-pivot-whale-farm-to-eight-pillars]]에 있습니다.

## 1. 재미 — 먼저 이것부터

앞선 기획의 실패는 **재미를 한 문장으로 말할 수 없다**는 것이었습니다. 그래서 이번에는 재미를
설계의 출발점에 놓고, 세 층으로 명시합니다.

### 재미 1 — 배치의 쾌감 (매 턴, 3초)
카드를 **어디에 놓는지**가 점수를 자릿수 단위로 바꿉니다. 같은 손패로 순서만 바꿔서
1,200점과 46,000점이 갈립니다. 이것은 "고민 → 배치 → 즉각적 시각 피드백"의 3초 루프이고,
퍼즐 게임이 20년간 검증한 가장 짧은 쾌감입니다.

### 재미 2 — 조합 발견의 쾌감 (매 판, 15분)
오행 상생은 **고리(chain)**입니다. 木→火→土→金→水→木. 고리가 길어질수록 배수가 곱해집니다.
여기에 십신 유물이 얹히면 "상생 1회당 +0.8배" 같은 곱셈이 곱셈에 붙습니다.
**플레이어는 매 판 자기만의 고장난 조합을 찾아냅니다.** 이것이 Balatro가 500만 장을 판 이유이고,
이 게임에는 Balatro에 없는 것이 하나 더 있습니다 — **상극(음의 인접효과)**. 좋은 카드를
잘못된 자리에 놓으면 뒤쪽 전체가 반토막 납니다. 그래서 배치가 실제 퍼즐이 됩니다.

### 재미 3 — 숫자 폭발과 자기 서사 (판의 끝, 공유)
8단계 대운을 지나며 목표 점수는 200 → 4,000 → 90,000 → 수백만으로 오릅니다.
마지막에 **命式 카드**가 출력됩니다 — 내가 조립한 팔자 여덟 칸, 최종 점수, 그리고 한 줄 감명.
한국에서 사주 결과 캡처는 **이미 자동으로 공유되는 포맷**입니다. 공유 장치를 새로 발명할
필요가 없습니다.

> **왜 이건 튜토리얼이 필요 없나:** 오행 상생상극은 한국·중국·일본·대만에서 **국민 상식**입니다.
> 木生火, 金剋木을 설명할 필요가 없습니다. 판타지 시스템을 새로 발명하는 게임이 첫 10분을
> 규칙 설명에 쓰는 동안, 이 게임은 첫 10초에 플레이가 시작됩니다. **이것이 이 소재를 고른
> 가장 큰 이유입니다** — 문화적 사전지식을 온보딩 비용 0으로 바꿔 씁니다.

## 2. 왜 이 소재인가 — 시장 논증

### 2.1 유료 차트가 실제로 사는 것 (2026-08-19 실측)

[[paid-appstore-number-one-2026]] §4 + 한국·일본 차트 실측에서 반복되는 패턴:

| 승자 유형 | 실례 | 공통점 |
|---|---|---|
| 카드/로그라이트 덱빌더 | Balatro(US 9위), Slay the Spire(US 14·KR 23·JP 5) | 짧은 판, 무한 조합, 곱셈 폭발 |
| 슬롯/도박 로그라이트 | CloverPit(US 22·JP 7), **Slots & Daggers(US 19·KR 8·JP 3)** | 릴이 돌아가는 한 장면 |
| 정적 일러스트 내러티브 | Servant of the Lake(US 3·KR 3), Sally Face(US 8), The Past Within(KR 11) | 애니메이션 0, 분위기로 판다 |
| 회사/경영 로그라이크 | **The Company: 로그라이크 회사 경영(KR 10)** | 숫자 성장 |
| 기이한 바이럴 프리미엄 | 스이카게임(KR 17·JP 상위) | 한 장면으로 설명됨 |

**결론:** 유료 차트는 **① 짧은 판 ② 무한 조합/성장 ③ 한 장면으로 읽히는 게임**을 삽니다.
애니메이션과 대작 아트는 조건이 아닙니다. `팔자`는 세 조건을 모두 충족합니다.

### 2.2 왜 한국을 먼저 노리는가 (근거: 실측)

- 미국 유료 게임 1위는 15년째 마인크래프트($6.99)입니다.
- **한국 유료 게임 1위는 `Paladog` — 2011년 한국 인디 게임입니다.** 마인크래프트는 2위입니다.
  **미국에서 안 무너진 벽이 한국에서는 이미 뚫려 있습니다.**
- 한국 유료 게임 Top 25에 소규모 로컬 타이틀이 6개 이상 있습니다
  (`야구 못하면 또 환생함`, `The Company`, `던전 머지!`, `서울 2033`, `화산의 딸` 등).
- 필요 볼륨이 자릿수 낮습니다 — 일본 Top 10 진입이 미국의 약 1/3.5(2019, 비게임) `[추정]`,
  한국은 그보다 더 낮을 것으로 추정 `[미검증]`.

여기에 `팔자`만의 추가 이점: **소재가 1차 시장의 모국어입니다.** 오행·사주는 한국에서
게임 규칙 설명이 필요 없고, 커뮤니티에서 즉시 화제가 되며, 사주 앱 시장이 이미 거대합니다.
상세: [[0025-whale-farm-korea-first]] (시장 결정은 이 기획에도 그대로 적용).

### 2.3 왜 Balatro의 아류가 아닌가

| | Balatro | 팔자 |
|---|---|---|
| 배치 | 카드 선택이 핵심, 위치는 부차적 | **위치가 핵심** — 인접 기둥의 오행 관계가 배수를 만듦 |
| 인접 효과 | 없음(조커는 전역) | **상생(양) / 상극(음)** — 좋은 카드를 잘못 놓으면 손해 |
| 사전지식 | 포커 핸드(서양권 상식) | 오행 상생상극(동아시아 상식) — 동일 전략, 다른 대륙 |
| 실패 형태 | 점수 미달 | 점수 미달 + **자기 조합이 스스로를 파괴** |

Balatro가 타로/조커라는 서양 점술 스킨으로 500만 장을 팔았다면, **오행은 그것의 동아시아 대응물**
입니다. 파생이 아니라 **같은 자리의 다른 문화권 버전**이고, 상극이라는 음의 인접효과가
배치 퍼즐이라는 새로운 결정 축을 추가합니다.

## 3. 코어 룰 (구현 가능한 수준까지)

### 3.1 판(命)과 보드

```
        年柱      月柱      日柱      時柱
天干  [ 카드 ]  [ 카드 ]  [ 카드 ]  [ 카드 ]      ← 하늘 줄
地支  [ 카드 ]  [ 카드 ]  [ 카드 ]  [ 카드 ]      ← 땅 줄
        └───── 상생/상극 고리는 좌 → 우로 흐른다 ─────┘
```

보드는 **4기둥 × 2줄 = 8칸**. 사주팔자 그 자체입니다.

### 3.2 카드 (간지)

각 카드는 다음을 가집니다.
- **오행**: 木 火 土 金 水
- **음양**: 陽 / 陰
- **기본값(氣)**: 8 ~ 30
- **십신 키워드**(선택): 比肩·食神·正財·偏官 등 — 카드 자체의 특수 규칙

### 3.3 채점 (한 판의 정산)

```
1) 기둥별 기본점 = 천간값 + 지지값
   · 두 카드가 같은 오행이면 (比肩)      → 기본점 +40%
   · 두 카드의 음양이 다르면 (陰陽和)    → 기본점 ×1.2
2) 기둥의 지배 오행 = 값이 큰 쪽의 오행
3) 좌→우로 인접 기둥 관계를 판정
   · 상생 (木→火→土→金→水→木)  → 고리 이어짐. 연속 n번째 링크는 배수 ×(1.5, 2.2, 3.5)
   · 상극 (木剋土 土剋水 水剋火 火剋金 金剋木) → 고리 끊김 + 이후 기둥 ×0.5
   · 무관계                       → 고리 끊김(패널티 없음)
4) 최종 점수 = Σ(기둥 기본점) × Π(활성 고리 배수) × Π(유물 배수)
```

**설계 의도:** 3)이 이 게임의 전부입니다. 손패가 같아도 배치 순서로 점수가 자릿수 단위로
갈리고, 상극은 "강한 카드를 어디에 두지 못하게" 만들어 매 턴 실제 고민을 만듭니다.

### 3.4 진행 (로그라이트 구조)

- 한 판 = **8 대운**. 각 대운마다 목표 점수가 상승(200 → 4,000 → 90,000 → 수백만).
- 대운 사이 **선택 드래프트 3택 1**:
  - **간지 카드** — 덱 확장
  - **십신 유물** — 지속 배수 ("상생 1회당 +0.8배", "土 기둥은 두 번 계산")
  - **신살(神煞) 저주** — 고위험 고보상 ("모든 배수 ×2, 단 상극이 하나라도 있으면 판 종료")
- **12지 원국(命 아키타입)** 해금 = 시작 덱 12종. 각각 다른 빌드 정체성(예: 亥水 = 상생 장인,
  申金 = 상극 역이용).

### 3.5 공유 장치 — 命式 카드

판이 끝나면 세로 이미지 1장이 생성됩니다: 완성된 팔자 여덟 칸, 최종 점수, 최장 상생 고리,
그리고 감명 한 줄("金水상관, 재물은 크되 오래 머물지 않는다"). **시드 번호가 박혀 있어 같은
운명을 남이 다시 돌려볼 수 있습니다.** 일간 시드 챌린지의 기반이자, 한국에서 이미 공유되는 포맷.

## 6. 기술

[[0022-whale-farm-godot-steam-first]]의 3층 구조를 그대로 승계합니다 — 이 부분은 유효했습니다.

1. **채점 엔진은 플랫폼 중립 TypeScript** (`apps/eight-pillars/sim/`). 순수 함수 + 결정론 시드.
2. **웹이 설계 리그** — 플레이어블 프로토타입과 몬테카를로 밸런싱이 같은 코드를 돕니다.
3. **출시 빌드는 Godot 4** — iOS 우선, 웹 데모는 HTML5 출력.

**밸런싱 하네스를 1급 자산으로 계승합니다.** 덱빌더의 생사는 "고장난 조합이 존재하되 항상
이기지는 않는가"에 달려 있고, 그건 손이 아니라 10만 판 시뮬레이션으로만 확인됩니다.
[[whale-farm]]에서 만든 몬테카를로 + 설계 명제 검증 패턴을 그대로 옮깁니다.

이 게임의 설계 명제(검증 대상):
1. **배치가 중요하다** — 같은 손패를 최적 배치 vs 무작위 배치했을 때 점수 차가 5배 이상
2. **조합에 천장이 없다** — 상위 1% 판의 점수가 중위 판의 100배 이상
3. **풀리지 않았다** — 탐욕적 최적화 AI의 승률이 40~70%
4. **상극이 실제 함정이다** — 무작위 배치 판의 30% 이상에서 상극 페널티 발생
5. **드래프트가 의미 있다** — 유물 선택을 무작위화하면 승률이 20%p 이상 하락

| 사주 소재가 미신·운세 앱으로 오인 | 운세를 점치지 않는다는 것을 명확히. **점수 게임**이지 점집이 아니다. 스토어 문구와 첫 화면에서 분리 |
| 오행 규칙을 게임 규칙으로 번역하는 난이도 | M1 하네스로 수치 검증. 규칙이 아름다워도 재미없으면 버린다 |
| 서구권 확장 시 문화 장벽 | Balatro의 타로처럼 **신비로운 카드 스킨**으로 읽히면 충분. 영어판은 오행을 Wood/Fire/Earth/Metal/Water로 직역 + 관계 화살표를 시각화 |
| 한국 1위의 홍보 가치가 미국보다 작다 | 1차 트로피를 자금·신뢰로 쓰고 2단(일본·미국)으로 확장하는 계획을 전제 |
| 1인 개발의 재미 검증 한계 | M1·M2를 최소 규모로 먼저 만들고, 재미가 없으면 이 기획도 폐기한다. **폐기 가능성을 로드맵에 내장** |
