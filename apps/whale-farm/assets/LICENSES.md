# WHALE FARM — 에셋 매니페스트 & 라이선스

이 파일은 **게임에 들어가는 모든 외부 에셋의 출처·라이선스·확인일**을 기록합니다.
에셋을 추가할 때 이 파일을 같이 갱신하지 않으면 그 에셋은 빌드에 들어갈 수 없습니다.
(근거: `wiki/decisions/0023-whale-farm-zero-asset-art-pipeline.md`)

## 규칙

1. **상업 이용이 명시적으로 허용된 것만** 사용합니다. 불확실하면 사용하지 않습니다.
2. **실존 게임·회사·인물을 식별 가능하게 만드는 에셋은 금지**합니다. 로고·캐릭터·UI 카피 포함.
3. AI 생성물은 **생성 도구 · 플랜 · 생성일 · 프롬프트**를 함께 기록합니다.
4. 유료 구매 에셋은 **라이선스 원문 링크와 구매 증빙 위치**를 기록합니다.

## 자체 제작 (외부 라이선스 없음)

| 에셋 | 방식 |
|---|---|
| UI 아이콘 세트 | Claude가 SVG로 직접 제작. 현재 프로토타입은 이모지 4개(🐋🐬🐟👻)로 대체 중 — 출시 빌드에서 자체 SVG로 교체 |
| 코호트 초상 / 사내 인물 | **절차적 생성**으로 결정: 이름 해시 → 하프톤 실루엣 + 이니셜. AI 이미지도 스톡도 필요 없음 |
| 차트·게이지·진척 바 | 전부 CSS/Canvas. 이미지 0장 |
| 결산 공유 카드 | Canvas 렌더링 (텍스트 + 수치) |
| 효과음 (프로토타입 단계) | WebAudio 합성. Kenney 팩 도입 전까지 파일 0개 |
| BGM | **미정** — 아래 참조 |

## 미해결 — 결정 필요

| 항목 | 상태 | 필요한 판단 |
|---|---|---|
| BGM 3~4트랙 | 미조달 | ① 로열티프리 구매(예산 소액) ② AI 생성 음악(상업권 확인 필요) ③ 무음 + 앰비언트 SFX만. **③이 톤에 가장 맞을 수 있음** — 사무실은 조용합니다 |
| AI 이미지 사용 여부 | **현재 계획상 불필요** | 절차적 초상으로 대체했으므로 AI 이미지 없이 출시 가능. 가차 카드 아트가 필요해지면 그때 상업권 있는 플랜에서 생성 |
| 한국어 폰트 | 미정 | 한국어 로컬라이즈 시 OFL 한글 폰트 필요 (예: Pretendard, IBM Plex Sans KR) |

## 현재 프로토타입의 외부 의존

`web/prototype.html`은 Google Fonts CSS 한 줄 외에 **외부 에셋 의존이 0**입니다.
이미지·오디오 파일이 하나도 없습니다. 이것이 이 아트 디렉션의 설계 목표였습니다.
