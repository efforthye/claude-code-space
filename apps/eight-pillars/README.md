# 팔자 / EIGHT PILLARS

여덟 장의 간지 카드를 네 기둥에 배치해 점수를 폭발시키는 로그라이트 덱빌더.
**같은 손패라도 어디에 놓느냐로 점수가 자릿수 단위로 갈립니다.**

- 기획서: `wiki/services/eight-pillars.md`
- 시장 근거: `wiki/concepts/paid-appstore-number-one-2026.md`
- 전환 근거: `wiki/decisions/0026-pivot-whale-farm-to-eight-pillars.md`

## 코어 규칙

```
        年柱   月柱   日柱   時柱
  天干  [카드] [카드] [카드] [카드]
  地支  [카드] [카드] [카드] [카드]
        └── 상생/상극은 좌 → 우로 흐른다 ──┘

相生 木→火→土→金→水→木   고리 이어짐. 연속 링크마다 ×1.5 → ×2.2 → ×3.5
相剋 木剋土 土剋水 水剋火 火剋金 金剋木   고리 끊김 + 이후 기둥 ×0.5
```

십신 유물이 이 규칙을 뒤집습니다. `偏官`·`魁罡`을 들면 **상극이 페널티가 아니라 배당**이 되고,
최적해가 상생 고리에서 삼연속 상극으로 완전히 뒤집힙니다.

## 구조

```
sim/
  elements.ts    오행 상생/상극 그래프 — 게임의 전부가 이 두 사이클
  cards.ts       천간 10 + 지지 12 (전통 오행·음양 그대로)
  score.ts       순수 채점 함수 — 이게 재미없으면 아래 전부 무의미
  relics.ts      십신 유물 10종. 어떤 유물도 '무조건 좋음'이면 안 됨
  run.ts         8 대운 + 드래프트 + 완전탐색 최적 배치(4!·4! = 576)
  montecarlo.ts  밸런싱 하네스 + 설계 명제 6개
rng.ts           시드 결정론 (일간 命式 챌린지의 전제)
```

## 실행

```bash
node sim/montecarlo.ts 3000    # 밸런싱 + 설계 명제 검증 + 샘플 보드 출력
```

## 설계 명제 (실패 가능한 형태)

밸런스를 건드린 뒤 이 6개가 통과하지 않으면 밸런스가 틀린 것입니다.
2026-08-22 실측 (2,000런):

| # | 명제 | 실측 |
|---|---|---|
| A1 | 배치가 중요하다 — 최적이 무심한 배치의 5배 이상 | **×31.2** |
| A2 | 빌드에 천장이 없다 — p99 최고점이 최종 목표의 10배 이상 | **×22.0** |
| A3 | 풀리지 않았다 — 최적+영리한 드래프트 승률 40~70% | **40.5%** |
| A4 | 상극이 실제 함정이다 — 무심한 보드의 30% 이상에서 상극 발생 | **52.0%** |
| A5 | 드래프트가 의미 있다 — 영리한 드래프트가 무작위보다 20%p 이상 | **40.5% vs 15.4%** |
| A6 | 죽은 유물이 없다 — 모든 유물이 3% 이상 선택됨 | **최저 偏官 4.4%** |

완전탐색이 576가지뿐이라 **게임 내 힌트 버튼이 곧 최적해**입니다. 이건 밸런싱에도,
튜토리얼에도, 데일리 챌린지 정답 공개에도 그대로 쓰입니다.

## 상태

**M1(채점 엔진 + 하네스) 완료.** 다음: M2 플레이어블 1판(웹), M3 命式 공유 카드.
