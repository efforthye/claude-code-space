### DNS records — needs an API token

Terraform imports DNS records by `<zone_id>/<record_id>`. With a token
exported (`CLOUDFLARE_API_TOKEN`, Zone:DNS:Read is enough for this step):

```bash
ZONE_ID=$(curl -s -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  "https://api.cloudflare.com/client/v4/zones?name=efforthye.dev" \
  | python3 -c 'import sys,json;print(json.load(sys.stdin)["result"][0]["id"])')

curl -s -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  "https://api.cloudflare.com/client/v4/zones/$ZONE_ID/dns_records?type=CNAME" \
  | python3 -c 'import sys,json;[print(r["id"], r["name"], r["content"]) for r in json.load(sys.stdin)["result"]]'
```

Then append one block per record to `infra/terraform/onprem/imports.generated.tf`:

```hcl
import {
  to = cloudflare_dns_record.tunnel["richclub.efforthye.dev"]
  id = "<zone_id>/<record_id>"
}
```
